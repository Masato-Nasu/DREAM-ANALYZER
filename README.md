# DREAM ANALYZER

**深層心理夢占い** — 夢を記録し、人物・場所・出来事・感情から心の奥にあるものを読み解くBYOK型PWAです。

## Features

- 夢の内容、目覚めたときの感情、最近の状況を入力
- 複数の心理学的な見方を内部で比較し、一つの読み解きとして表示
- 初診後の質問に一度回答し、初診を残したまま再診断を表示
- 過去の夢をブラウザ内に保存
- AIが関連する過去の夢を選択し、複数の夢を時系列で分析
- 夢・分析結果・自由連想をJSONで書き出し
- OpenAI APIキーを保存しないBYOK方式
- ホーム画面へのインストールとオフライン起動に対応

## PWA

対応ブラウザでサイトを開き、ブラウザメニューの「アプリをインストール」または「ホーム画面に追加」を選択してください。

## Privacy

夢と分析結果はブラウザのローカルストレージに保存されます。APIキーは保存しません。ブラウザデータを削除すると記録も消えるため、必要に応じてJSONを書き出してください。

## Notes

本アプリは医療診断、心理療法、未来予測を行うものではありません。結果は、自分の経験や感情を振り返るための探索的な読み解きです。
